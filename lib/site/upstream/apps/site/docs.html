01
FIRST BOARD

安装并创建第一个画布

应用通常只需要主包。节点数据类型由应用注册，注册后再创建节点；这样每个节点的 props 都有明确的校验和序列化规则。

import { createPixiBoard, type CustomNodeDefinition } from "pixiboardjs";

const rect: CustomNodeDefinition<{ fill: number }> = {
  type: "app.rect", version: 1,
  defaults: { fill: 0x7c8cf8 },
  validate: (value) => ({ fill: typeof (value as any)?.fill === "number"
    ? (value as any).fill : 0x7c8cf8 }),
  getBounds: (node) => ({ minX: node.x, minY: node.y,
    maxX: node.x + node.width, maxY: node.y + node.height }),
};

const board = await createPixiBoard({
  container: document.querySelector("#board"),
});
await board.nodeTypes.register(rect);
await board.ready;

const node = await board.nodes.create({
  type: "app.rect", x: 40, y: 40, width: 120, height: 80,
  props: { fill: 0x7c8cf8 },
});
提示board.ready 表示运行时准备完成。省略 container 可以创建 headless board，但 capture 等需要 renderer 的能力不可用。
02
DOCUMENT MODEL

节点 API

节点是扁平、可序列化的数据。通过 ID 操作节点，不需要接触 Store、Pixi DisplayObject 或渲染缓存。

nodes.create(input)

创建节点并返回 NodeHandle。

nodes.get(id)

读取当前不可变节点快照。

nodes.update(id, patch)

更新几何属性或业务 props。

nodes.remove(id)

删除节点并产生可撤销变更。

nodes.list(filter)

按类型、ID、可见性等条件查询。

node(id)

使用 x()、setAttrs() 和 on("change") 操作 handle。

03
EDITING FLOW

事务、选择与视口

事务和历史

多个写入可以组成一个原子操作，失败时不会部分提交。coalesceKey 可以将连续手势合并为一个 undo step。

board.transaction("Arrange", () => {
  board.nodes.update("a", { x: 0, y: 0 });
  board.nodes.update("b", { x: 240, y: 0 });
}, { origin: "api" });

选择和视口

选择状态与文档节点分离。视口 API 负责平移、缩放、适配和坐标转换。

board.selection.set(["a", "b"]);
board.viewport.fitNodes(["a", "b"]);
board.viewport.zoomAt({ x: 400, y: 300 }, 1.2);
04
EXTEND THE CANVAS

自定义节点

通过 board.nodeTypes.register() 定义 defaults、validate、getBounds 和可选 resize 策略。需要绘制时，在同一个定义中提供 renderer 的 create、update、destroy。

◇数据定义校验、默认值、bounds、resize
◈渲染定义创建、更新和销毁显示对象
↻可重建离屏后从最新 JSON 恢复
边界业务状态应写入 node.props，不要只保存在渲染对象中。这样保存、重载和 Agent 读取都能得到同一份状态。

FROM THE SITE

选择、编辑、历史与媒体节点

下面是交互 Demo 中已经验证过的一套通用实现方式：数据定义保持扁平，交互统一进入事务和历史，renderer 只管理可重建的显示对象。

□多选与框选selection.set / toggle + 屏幕到世界坐标转换
T文字编辑DOM textarea overlay，提交回 node.props
↻Undo / redotransaction + coalesceKey 合并连续手势
function selectInScreenRect(start, end) {
  const a = board.viewport.toWorld(start);
  const b = board.viewport.toWorld(end);
  const rect = { minX: Math.min(a.x, b.x), minY: Math.min(a.y, b.y),
    maxX: Math.max(a.x, b.x), maxY: Math.max(a.y, b.y) };
  const ids = board.nodes.list().filter((node) =>
    node.x < rect.maxX && node.x + node.width > rect.minX &&
    node.y < rect.maxY && node.y + node.height > rect.minY).map((node) => node.id);
  board.selection.set(ids);
}

board.transaction("Move selection", () => {
  for (const origin of dragOrigins) {
    board.nodes.update(origin.id, { x: origin.x, y: origin.y });
  }
}, { origin: "ui", coalesceKey: `move:${gestureId}` });

文字编辑

编辑态沿用渲染态 typography，并用不透明背景覆盖原文字，避免虚影。

const text = editor.value.replace(/\r\n/g, "\n");
board.transaction("Edit text", () => {
  board.nodes.update(nodeId, { height: measureTextHeight(text),
    props: { ...current.props, text } });
}, { origin: "ui" });

图片 / 视频 / 音频

共用一个数据定义工厂；image/video 保持比例，audio 固定高度。实际纹理由 assetRefs 和 renderer lease 提供。

const media = mediaDefinition("video");
await board.nodeTypes.register(media);
await board.nodes.create({
  type: "video", width: 320, height: 180,
  props: { name: "demo.mp4", mimeType: "video/mp4", size: 0 },
  assetRefs: { poster: { assetId: "asset-1", variant: "preview" } },
});
原则节点数据放在 props / assetRefs；DOM overlay 只承载编辑交互；renderer 实现 create / update / destroy，离屏后可以从最新文档重建。

07
AUTOMATION READY

Agent tools

安装 @pixi-board/agent-tools 后，可以把 canvas.read 和 canvas.write 交给自己的 Agent harness。工具包提供 schema、校验、分页和可序列化错误，但不内置 MCP 或 HTTP server。

import { createPixiBoardAgentTools } from "@pixi-board/agent-tools";

const tools = createPixiBoardAgentTools(board.capabilities);
await tools.call("canvas.write", {
  type: "create",
  nodes: [{ type: "app.rect", x: 0, y: 0, width: 100, height: 60, props: { fill: 0x52d68e } }],
});
